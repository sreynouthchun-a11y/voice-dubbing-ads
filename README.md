# Voice Dubbing Ads

AI Dubbing Auto Voice — High-Speed Khmer Dubbing Web App.

A clean static front-end recreation of the AI Dubbing Auto Voice interface.

## Features
- Browser-like top bar with the address hidden
- Blue action card (Male / Female / Auto Sync)
- Script table in Gemini format
- Fully responsive

## Run locally
```bash
# any static server works
npx serve .
```

## Deploy
This project is deployed on Vercel.
