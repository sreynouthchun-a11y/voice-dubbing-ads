# NiceOne Dubber — AI Dubbing Auto Voice

High-Speed Khmer Dubbing web app. Paste a Khmer script with start–end timestamps and speaker tags, get male or female speech for each line automatically (up to 10+ minutes).

## Features
- Browser-like top bar with the Hugging Face address **hidden**
- Blue action card: សំឡេងប្រុស [M] / សំឡេងស្ត្រី [F] / Auto Sync
- Script table in Gemini format (START / END / SPEAKER / TRANSLATE KHMER)
- Fully responsive

## Run locally
```bash
npx serve .
```
